# Sales 101 skill and source map

Created from the three user-supplied Agent J Sales 101 PDFs reviewed on 2026-09-08: `week1-icp-deck.pdf` (14 pages), `week2-offer-deck.pdf` (14 pages), and `curriculum-deck.pdf` (15 pages). Page numbers below are PDF page positions, not lesson numbers. The PDFs remain outside this public package; each skill carries the guidance it needs.

This collection turns classroom material into usable assistant workflows. Classroom directives such as posting homework or writing in the live chat are lesson content, not authorization for a skill to publish or send. The curriculum's Week 1 label "SKILL: NONE" describes the original lesson, not a restriction on creating an ICP skill.

## How these fit existing skills

The new collection focuses on the first-client workflow, small field tests, and evidence handoffs. Existing `hundred-million-offers`, `offer-stack-builder`, and `hormozi-pitch` cover broader offer work; `kara-cold-outbound`, `linkedin-signal-miner`, and `lead-magnet-factory` provide channel depth; `kellen-copy-coach` provides deeper copy critique. They are optional complements, not runtime dependencies. No existing skills were replaced.

## Portability and scope

All ten skills use YAML frontmatter plus Markdown and include `agents/openai.yaml` for Codex UI metadata. Root folders are canonical. Claude marketplace registration, the `sales-101` Codex plugin collection, and `.agents/skills`, `.claude/skills`, and `.cursor/skills` links expose the same content. Only the first-meeting skill needs an additional reference file, which ships in its folder. A chat assistant can also use the files as supplied instructions where native skill installation is unavailable; no specific ChatGPT or "Astro" installation surface is assumed or claimed tested.

The 7-day ICP experiment comes from the Week 1 deck. The 30-day first-meeting and 90-day first-client goals operationalize the user's request. They are targets, not guaranteed results. Generated role-play is labeled simulation and cannot count toward buyer validation, bookings, or paid-client results.
